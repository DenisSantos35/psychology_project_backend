PSYCOLOGI API - GUIA PARA INSOMNIA
==================================

1. AMBIENTE
-----------

Crie um Environment no Insomnia:

{
  "base_url": "http://localhost:3000/api/v1",
  "health_url": "http://localhost:3000",
  "access_token": "",
  "refresh_token": "",
  "user_id": "",
  "patient_id": "",
  "appointment_id": "",
  "history_id": "",
  "session_id": "",
  "note_id": "",
  "payment_id": "",
  "consultation_id": ""
}

Se o PORT da sua .env for 3333, troque 3000 por 3333.

Headers para rotas privadas:
Authorization: Bearer {{ _.access_token }}
Content-Type: application/json

Todas as respostas usam o envelope "data". Listas também retornam "meta".


2. HEALTH CHECKS
----------------

GET {{ _.health_url }}/health/live

GET {{ _.health_url }}/health/ready


3. AUTENTICAÇÃO
---------------

POST {{ _.base_url }}/auth/register
Body JSON:
{
  "name": "Ana Souza",
  "cpf": "52998224725",
  "dateOfBirth": "1990-01-01",
  "gender": "female",
  "phone": "11999999999",
  "email": "ana@email.com",
  "address": {
    "cep": "01001000",
    "street": "Praca da Se",
    "neighborhood": "Se",
    "city": "Sao Paulo",
    "stateCode": "SP",
    "number": "100",
    "complement": "Sala 2"
  },
  "professionalType": "psychologist",
  "professionalLicense": "CRP-12/990321",
  "specialty": "Psicologia Clinica",
  "password": "Senha@123",
  "confirmPassword": "Senha@123"
}

POST {{ _.base_url }}/auth/login
Body JSON:
{
  "email": "ana@example.com",
  "password": "SenhaForte@123"
}

Copie accessToken e refreshToken da resposta para o Environment.

POST {{ _.base_url }}/auth/refresh
Body JSON:
{
  "refreshToken": "{{ _.refresh_token }}"
}

POST {{ _.base_url }}/auth/logout
Header privado obrigatório.

GET {{ _.base_url }}/auth/me
Header privado obrigatório.

POST {{ _.base_url }}/auth/forgot-password
Body JSON:
{
  "email": "ana@example.com"
}


4. USUÁRIOS
-----------

GET {{ _.base_url }}/users
Somente administradores.

GET {{ _.base_url }}/users/{{ _.user_id }}

PATCH {{ _.base_url }}/users/{{ _.user_id }}
Body JSON:
{
  "name": "Ana Souza",
  "plan": "professional"
}

DELETE {{ _.base_url }}/users/{{ _.user_id }}
Realiza soft delete.


5. AJUSTES DO PROFISSIONAL
--------------------------

GET {{ _.base_url }}/professional-profiles/me
Header privado obrigatório.

PATCH {{ _.base_url }}/professional-profiles/me
Body JSON, envie somente os campos alterados:
{
  "name": "Ana Souza",
  "email": "novo@email.com",
  "phone": "(11) 98888-7777",
  "specialty": "Psicologia Comportamental",
  "address": {
    "cep": "01001-000",
    "stateCode": "sp",
    "complement": "Sala 3"
  }
}

Não podem ser alterados por essa rota: role, plan, isActive, userId, cpf,
createdAt e avatarUrl.

6. AGENDAMENTOS / AGENDA
------------------------

GET {{ _.base_url }}/appointments?page=1&limit=20

Filtros opcionais:
GET {{ _.base_url }}/appointments?status=pending&dateFrom=2026-06-01T00:00:00-03:00&dateTo=2026-06-30T23:59:59-03:00

GET {{ _.base_url }}/appointments/{{ _.appointment_id }}

POST {{ _.base_url }}/appointments
Body JSON:
{
  "patientId": "{{ _.patient_id }}",
  "startsAt": "2026-06-22T14:00:00-03:00",
  "endsAt": "2026-06-22T15:00:00-03:00",
  "description": "Sessão de acompanhamento"
}

PATCH {{ _.base_url }}/appointments/{{ _.appointment_id }}
Body JSON:
{
  "startsAt": "2026-06-22T15:00:00-03:00",
  "endsAt": "2026-06-22T16:00:00-03:00",
  "description": "Horário reagendado"
}

PATCH {{ _.base_url }}/appointments/{{ _.appointment_id }}/confirm
Sem body.

PATCH {{ _.base_url }}/appointments/{{ _.appointment_id }}/cancel
Body JSON:
{
  "reason": "Solicitação do paciente"
}

As mesmas rotas podem usar /schedule no lugar de /appointments.
Status internos: pending, confirmed, completed, cancelled.

10. PAGAMENTOS
--------------

GET {{ _.base_url }}/payments/{{ _.payment_id }}

GET {{ _.base_url }}/sessions/{{ _.session_id }}/payments

POST {{ _.base_url }}/payments
Body JSON:
{
  "sessionId": "{{ _.session_id }}",
  "amount": "250.00",
  "status": "pending",
  "dueAt": "2026-06-25T12:00:00-03:00",
  "paymentMethod": "pix"
}

PATCH {{ _.base_url }}/payments/{{ _.payment_id }}
Body JSON:
{
  "status": "paid",
  "paidAt": "2026-06-23T10:30:00-03:00",
  "paymentMethod": "pix"
}

Status: pending, paid, overdue, cancelled, refunded.
amount deve ser enviado como string decimal.
